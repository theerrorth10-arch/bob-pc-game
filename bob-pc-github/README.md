# ชื่อบิดาท่านตัวเย็น — PC Shop Game

เกมร้านประกอบคอมด้วย HTML, CSS และ JavaScript เปิดเล่นผ่าน `index.html` ได้ทันที ไม่ต้องติดตั้งโปรแกรมเพิ่มเติม

## วิธีเล่น
1. รับออร์เดอร์ที่หน้าร้าน
2. ซื้อและติดตั้งอะไหล่ หรือใช้ชุดแนะนำ
3. เล่นมินิเกมขันน็อต ทาซิลิโคน CPU และเสียบสายไฟ
4. ทดสอบเครื่องแล้วส่งมอบเพื่อรับเงินและสะสมกำไร

## คุณสมบัติ
- ตัวละครนักเรียนชายหัวโต ตากลม
- โมเดลอะไหล่ SVG 11 ชนิด รวมสินค้า 22 รุ่น
- เมนูหน้าร้าน ซื้ออะไหล่ โต๊ะประกอบ และคลังสินค้า
- ตรวจสเปกและความเข้ากันของอุปกรณ์
- รองรับหน้าจอมือถือแนวตั้งและแนวนอน
- บันทึกความคืบหน้าในเบราว์เซอร์เมื่อรองรับ
- เล่นออฟไลน์ได้
- เอฟเฟกต์ตอนทดสอบเครื่อง (สแกน ไฟฟ้าแลบ มิเตอร์ สั่นตามด่าน), ตอนผ่าน (PASS) และตอนส่งมอบ (พลุ กระดาษสี เหรียญบิน) พร้อมเสียงสังเคราะห์ ปิดเสียงได้ที่ปุ่มมุมซ้ายล่าง

## ไฟล์
- `index.html`: หน้าเริ่มเกมสำหรับเว็บและ GitHub Pages
- `pc-shop-game.html`: เกมฉบับไฟล์เดิม
- `pc-models/`: โมเดลอุปกรณ์ SVG แยกไฟล์

ข้อมูลราคา ยี่ห้อ และสเปกเป็นข้อมูลสมมติสำหรับเกม ไม่ใช่คำแนะนำซื้อคอมจริง
